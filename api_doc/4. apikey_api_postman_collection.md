# Postman Testing: API Key Endpoints

এখানে `API Key` মডিউলের API গুলো Postman-এ টেস্ট করার জন্য বিস্তারিত রিকোয়েস্ট এবং রেসপন্সের উদাহরণ দেওয়া হলো। 

> [!IMPORTANT]
> **Authorization Required:** 
> এই রাউটগুলো `authGuard()` দিয়ে প্রোটেক্টেড, তাই শুধুমাত্র লগিন করা ইউজাররাই এক্সেস পাবে। Postman-এ রিকোয়েস্ট পাঠানোর সময় `Authorization` হেডারে `Bearer <user_access_token>` দিতে ভুলবেন না।

---

## 1. Generate API Key (`POST /api/v1/api-keys/generate`)

এই এপিআইটির মাধ্যমে ইউজার তার ড্যাশবোর্ডের জন্য নতুন একটি API Key জেনারেট করতে পারবে। 

> [!WARNING]
> **Key Storage:**
> রেসপন্সে যে `apiKey` রিটার্ন হবে সেটি শুধুমাত্র একবারই দেখা যাবে (হ্যাস করে সেভ করা হয়)। তাই জেনারেট করার পর এটি ইউজারকে কপি করে নিতে হবে।

> [!TIP]
> **Generation Limits:**
> - **Free User:** একসাথে সর্বোচ্চ **১টি** একটিভ API Key তৈরি করতে পারবে।
> - **Subscribed User:** একসাথে সর্বোচ্চ **২০টি** একটিভ API Key তৈরি করতে পারবে।

### Request Details
- **Method:** `POST`
- **URL:** `{{base_url}}/api/v1/api-keys/generate`
- **Headers:**
  - `Authorization`: `Bearer {{access_token}}`

### Responses

#### 🟢 Success Response (201 Created)
```json
{
  "success": true,
  "statusCode": 201,
  "message": "API Key generated successfully. Save it now, it will not be shown again.",
  "data": {
    "apiKey": "bazi_abc123xyz456...",
    "id": "key_uuid_here",
    "prefix": "bazi_abc12",
    "isActive": true,
    "createdAt": "2023-10-01T00:00:00.000Z"
  }
}
```

## 2. Get All API Keys (`GET /api/v1/api-keys`)

ইউজার তার তৈরি করা সকল API Key এর তালিকা (শুধু প্রিফিক্স, ফুল কি নয়) এবং স্ট্যাটাস দেখতে পারবে।

### Request Details
- **Method:** `GET`
- **URL:** `{{base_url}}/api/v1/api-keys`
- **Headers:**
  - `Authorization`: `Bearer {{access_token}}`

### Responses

#### 🟢 Success Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "API Keys retrieved successfully",
  "data": [
    {
      "id": "key_uuid_here",
      "prefix": "bazi_abc12",
      "isActive": true,
      "createdAt": "2023-10-01T00:00:00.000Z"
    }
  ]
}
```

---

## 3. Revoke API Key (`PATCH /api/v1/api-keys/:keyId/revoke`)

যদি ইউজারের API Key কম্প্রোমাইজ হয়ে যায় বা সে ডিলিট করতে চায়, তবে এই এপিআই দিয়ে সেটি Revoke (অকেজো) করতে পারবে।

### Request Details
- **Method:** `PATCH`
- **URL:** `{{base_url}}/api/v1/api-keys/{{keyId}}/revoke`
- **Headers:**
  - `Authorization`: `Bearer {{access_token}}`

### Responses

#### 🟢 Success Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "API Key revoked successfully",
  "data": {
    "id": "key_uuid_here",
    "isActive": false
  }
}
```

# BaZi API Test Using API Key

> [!NOTE]
> **API Key Guard & Expiry:**
> `BaZi` মডিউলের `/api/v1/bazi/calculate` রাউটটি `apiKeyGuard()` দিয়ে প্রোটেক্টেড। এখানে হিট করতে ইউজারের লগিন টোকেন লাগবে না, বরং `API Key` লাগবে।
> 
> 🔴 **Free User Expiry Rule:** Free ইউজারদের তৈরি করা API Key **১০ দিন পর স্বয়ংক্রিয়ভাবে অকেজো (Revoke)** হয়ে যাবে এবং তখন `401 Unauthorized` ইরর দিবে।

## 4. Calculate BaZi (`POST /api/v1/bazi/calculate`)

এই রাউটে হিট করার সময় হেডারে `x-api-key` পাস করতে হবে।

### Request Details
- **Method:** `POST`
- **URL:** `{{base_url}}/api/v1/bazi/calculate`
- **Headers:**
  - `Content-Type`: `application/json`
  - `x-api-key`: `{{your_generated_api_key}}`

### Request Body
```json
{
  "birthDate": "1998-08-12",
  "birthTime": "10:30",
  "gender": "male",
  "timezone": "Asia/Dhaka",
  "language": "en"
}
```

#### 🟢 Success Response (200 OK)

> [!TIP]
> **14-Day Free Trial Logic:**
> - কোনো ইউজার একাউন্ট খোলার পর প্রথম **১৪ দিন** Subscribed ইউজারের মতোই সম্পূর্ণ (Full) রেসপন্স পাবে।
> - **১৪ দিন পার হয়ে যাওয়ার পর** এবং ইউজার যদি **Free প্ল্যানে** থাকে, তবে রেসপন্স থেকে `hiddenStems`, `tenGods`, `naYin`, `zodiac`, `constellation`, `solarTerms`, `luckPillars`, এবং `analysis.godsAndStars` ইত্যাদি ফিল্ডগুলো **null** করে দেওয়া হবে। (শুধুমাত্র বেসিক solar, lunar, pillars এবং fiveElements রেসপন্সে আসবে)।

```json
{
  "success": true,
  "statusCode": 200,
  "message": "BaZi calculated successfully.",
  "data": {
     // ...bazi data
  }
}
```

#### 🔴 Invalid API Key Error (401 Unauthorized)
যদি API Key ভুল হয় বা revoke করা থাকে:
```json
{
  "success": false,
  "statusCode": 401,
  "message": "Invalid API Key",
  "data": null
}
```
