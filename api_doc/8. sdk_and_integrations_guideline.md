## 1. TypeScript & JavaScript SDK (`bazi-sdk` / `@bazi/sdk`)

### 1.1 Core Principles

- **Zero External Dependencies:** Built using native `fetch` (compatible with Node.js 18+, Bun, Deno, Next.js Edge Runtime, Cloudflare Workers, and modern browsers).
- **100% Strict Type Safety:** Autocomplete for all BaZi chart properties (Heavenly Stems, Earthly Branches, Ten Gods, Luck Pillars, Growth Phases).
- **Dual Module Output:** Bundled with `tsup` into both ESM (`import`) and CommonJS (`require`) with source maps and `.d.ts` declaration files.
- **Isomorphic Utilities:** Includes built-in HMAC-SHA256 webhook signature verification.

### 1.3 TypeScript Client Implementation Example

```typescript
// src/client.ts
import { IBaziRequest, IBaziResponseData } from "./types";
import { BaziApiError, AuthenticationError, RateLimitError } from "./errors";
import { WebhookService } from "./webhooks";

export interface BaziClientOptions {
  apiKey: string;
  baseUrl?: string;
  timeout?: number;
  maxRetries?: number;
}

export class BaziClient {
  private readonly apiKey: string;
  private readonly baseUrl: string;
  private readonly timeout: number;
  private readonly maxRetries: number;
  public readonly webhooks: WebhookService;

  constructor(options: BaziClientOptions) {
    if (!options.apiKey) {
      throw new Error("BaZi API key is required to initialize BaziClient.");
    }
    this.apiKey = options.apiKey;
    this.baseUrl = (
      options.baseUrl || "https://api.baziapi.pro/api/v1"
    ).replace(/\/$/, "");
    this.timeout = options.timeout || 10000;
    this.maxRetries = options.maxRetries ?? 2;
    this.webhooks = new WebhookService();
  }

  public async calculate(request: IBaziRequest): Promise<IBaziResponseData> {
    const url = `${this.baseUrl}/bazi/calculate`;
    let attempt = 0;

    while (attempt <= this.maxRetries) {
      try {
        const controller = new AbortController();
        const timeoutId = setTimeout(() => controller.abort(), this.timeout);

        const response = await fetch(url, {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            "x-api-key": this.apiKey,
            "User-Agent": "bazi-sdk-js/1.0.0",
          },
          body: JSON.stringify(request),
          signal: controller.signal,
        });

        clearTimeout(timeoutId);

        if (response.ok) {
          const json = await response.json();
          return json.data;
        }

        if (response.status === 401) {
          throw new AuthenticationError("Invalid or missing API key.");
        }

        if (response.status === 429) {
          throw new RateLimitError(
            "Rate limit exceeded. Please check your plan quota.",
          );
        }

        const errorBody = await response.text();
        throw new BaziApiError(
          `API request failed with status ${response.status}: ${errorBody}`,
          response.status,
        );
      } catch (error: any) {
        attempt++;
        if (
          attempt > this.maxRetries ||
          error instanceof AuthenticationError ||
          error instanceof RateLimitError
        ) {
          throw error;
        }
        await new Promise((res) => setTimeout(res, Math.pow(2, attempt) * 500));
      }
    }

    throw new BaziApiError(
      "Failed to execute calculation after maximum retries.",
      500,
    );
  }
}
```

### 1.4 Webhook Signature Verification Utility

```typescript
// src/webhooks.ts
import crypto from "crypto";

export class WebhookService {
  public verifySignature(options: {
    payload: string | Buffer;
    signature: string;
    secret: string;
  }): boolean {
    const { payload, signature, secret } = options;
    if (!payload || !signature || !secret) return false;

    const rawBody =
      typeof payload === "string" ? payload : payload.toString("utf-8");
    const expectedSignature = crypto
      .createHmac("sha256", secret)
      .update(rawBody)
      .digest("hex");

    return crypto.timingSafeEqual(
      Buffer.from(signature),
      Buffer.from(expectedSignature),
    );
  }
}
```

## 2. Python SDK (`bazi-sdk` on PyPI)

### 2.1 Developer Experience (DX)

```python
from bazi import BaziClient, BaziError

client = BaziClient(api_key="bazi_your_api_key_here")

try:
    chart = client.calculate(
        birth_date="1998-08-12",
        birth_time="10:30",
        gender="male",
        timezone="Asia/Shanghai",
        language="en"
    )
    print(f"Day Master: {chart.heavenly_stems.day_stem}")
    print(f"Dominant Element: {chart.analysis.strongest_element}")
except BaziError as e:
    print(f"Calculation failed: {e}")
```

## 4. No-Code & Automation Connectors

### 4.1 n8n Community Node (`n8n-nodes-bazi`)

- **Package Name:** `n8n-nodes-bazi` (Published to npm)
- **Credentials:** `baziApi` (Field: `apiKey`, tested against `/api/v1/bazi/calculate`)
- **Operations:**
  1. `Calculate Chart` (Input: Birth Date, Time, Gender, Timezone)
  2. `Trigger: Daily BaZi Shift` (Webhook receiver node)
  3. `Trigger: Solar Term Changed` (Webhook receiver node)

### 4.2 Zapier Integration (Zapier Developer Platform)

- **Authentication:** API Key Authentication (Header: `x-api-key`)
- **Triggers:**
  - `New Solar Term Started` (Instant Webhook)
  - `Daily Element Shift` (Instant Webhook)
- **Actions:**
  - `Calculate Four Pillars Chart` (Creates structured JSON output for ChatGPT / Airtable / Slack nodes)

### 4.3 Make.com (Integromat) Custom App

- **Module 1 (Action):** `Calculate Chart` (Performs POST request with pre-mapped JSON bundle)
- **Module 2 (Instant Trigger):** `Watch Webhook Events` (Registers webhook URL via BaZi API `/api/v1/custom-webhooks`)

## 6. Release & Publishing Checklist

1. **GitHub Repository:** Setup `bazi-sdk-js` and `bazi-sdk-python` as public open-source repos with GitHub Actions CI/CD.
2. **NPM Registry:** Publish under `@bazi/sdk` or `bazi-sdk` with automated semantic versioning (`release-please` or `changesets`).
3. **PyPI Registry:** Publish `bazi-sdk` using `flit` or `poetry` with automatic wheel builds.
4. **Documentation Hub:** Embed live interactive SDK code snippets directly in your Next.js documentation portal.
