# Postman Testing: User API Endpoints

নতুন তৈরি করা `User` মডিউলের API গুলো Postman-এ টেস্ট করার জন্য রিকোয়েস্ট এবং রেসপন্সের উদাহরণ নিচে দেওয়া হলো। 

> [!IMPORTANT]
> **Authorization Required:** 
> এই সবগুলো রাউট শুধুমাত্র `ADMIN` এবং `SUPER_ADMIN` এর জন্য এক্সেসিবল। তাই Postman-এ রিকোয়েস্ট পাঠানোর সময় `Authorization` হেডারে `Bearer <admin_or_superadmin_access_token>` দিতে ভুলবেন না।

---

## 1. Get All Users (`GET /api/v1/users`)

আপনি চাইলে `query parameters` ব্যবহার করে ইউজারদের ফিল্টার, সার্চ বা পেজিনেশন করতে পারেন।
**Query Parameters (Optional):**
- `page` (default: 1)
- `limit` (default: 10)
- `search` (name বা email দিয়ে সার্চ করার জন্য)
- `status` (`active` বা `blocked`)
- `role` (`USER`, `ADMIN`, `SUPER_ADMIN`)
- `isDeleted` (`true` বা `false`, default: `false`)

**Request Body:**
*(None required for GET request)*

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Users retrieved successfully",
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 5
  },
  "data": [
    {
      "id": "uuid-string-here",
      "name": "John Doe",
      "email": "john@example.com",
      "country": "Bangladesh",
      "role": "USER",
      "isEmailVerified": true,
      "status": "active",
      "isDeleted": false,
      "createdAt": "2026-08-09T10:00:00.000Z",
      "updatedAt": "2026-08-09T10:00:00.000Z"
    }
  ]
}
```

## 3. Update User Status (`PATCH /api/v1/users/:id/status`)

**Request Path Variable:**
- `:id` = ইউজারের UUID

**Request Body (JSON):**
```json
{
  "status": "blocked"
}
```
*(Options: `active` বা `blocked`)*

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "User status updated successfully",
  "data": {
    "id": "uuid-string-here",
    "name": "John Doe",
    "email": "john@example.com",
    "status": "blocked",
    "role": "USER"
  }
}
```

## 4. Bulk Soft Delete (`POST /api/v1/users/bulk-soft-delete`)

> [!WARNING]
> আপনি যদি `ADMIN` হিসেবে লগিন করে থাকেন, আর এই লিস্টে কোনো `SUPER_ADMIN` এর আইডি থাকে, তাহলে রিকোয়েস্ট ফেইল করবে।

**Request Body (JSON):**
```json
{
  "userIds": [
    "uuid-string-user1",
    "uuid-string-user2"
  ]
}
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "2 users have been soft deleted.",
  "data": null
}
```
