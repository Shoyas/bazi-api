# Postman Testing: Subscription API Endpoints

এখানে `Subscription` মডিউলের API গুলো Postman-এ টেস্ট করার জন্য বিস্তারিত রিকোয়েস্ট এবং রেসপন্সের উদাহরণ দেওয়া হলো। 

> [!IMPORTANT]
> **Authorization Required:** 
> এই রাউটটি `authGuard()` দিয়ে প্রোটেক্টেড, তাই শুধুমাত্র লগিন করা ইউজাররাই এক্সেস পাবে। Postman-এ রিকোয়েস্ট পাঠানোর সময় `Authorization` হেডারে `Bearer <user_access_token>` দিতে ভুলবেন না।

---

## 1. Get Checkout URL (`POST /api/v1/subscriptions/checkout`)

এই এপিআইটির মাধ্যমে ইউজাররা লেমনস্কুইজি (LemonSqueezy) সাবস্ক্রিপশন চেকআউটের লিংক জেনারেট করতে পারবে। ইউজারের পছন্দমতো প্ল্যান অনুযায়ী এই পেমেন্ট URL জেনারেট হবে।

### Request Details
- **Method:** `POST`
- **URL:** `{{base_url}}/api/v1/subscriptions/checkout`
- **Headers:**
  - `Content-Type`: `application/json`
  - `Authorization`: `Bearer {{access_token}}`

### Request Body (JSON)
```json
{
  "plan": "MONTHLY"
}
```
> [!NOTE]
> **Available Options:** `plan` ফিল্ডে `"MONTHLY"` অথবা `"YEARLY"` পাঠাতে হবে।

### Responses

#### 🟢 Success Response (200 OK)
যখন চেকআউট URL সফলভাবে তৈরি হবে:

```json
{
  "success": true,
  "statusCode": 200,
  "message": "Checkout URL generated successfully",
  "data": {
    "checkoutUrl": "https://your-store.lemonsqueezy.com/checkout/buy/variant_id?custom=some_custom_data"
  }
}
```

#### 🔴 Validation Error (400 Bad Request)
যদি `plan` ফিল্ডে ভুল ভ্যালু দেওয়া হয় বা না দেওয়া হয়:

```json
{
  "success": false,
  "message": "Validation Error",
  "errorMessages": [
    {
      "path": "plan",
      "message": "Invalid plan type. Must be MONTHLY or YEARLY."
    }
  ]
}
```

#### 🔴 Unauthorized Error (401 Unauthorized)
যদি `Authorization` হেডার না দেওয়া হয় বা টোকেন ইনভ্যালিড হয়:

```json
{
  "success": false,
  "statusCode": 401,
  "message": "You are not authorized!",
  "data": null
}
```

---

> [!TIP]
> **Postman-এ টেস্ট করার টিপস:**
> - প্রথমে `/api/v1/auth/login` থেকে লগিন করে টোকেনটি নিয়ে নিন।
> - সেই টোকেনটি Postman এর Environment Variable-এ `access_token` হিসেবে সেভ করে রাখলে কাজ করতে সুবিধা হবে।
> - `checkoutUrl` পাওয়ার পর সেটি ব্রাউজারে ওপেন করে পেমেন্ট ফ্লো ঠিকমতো কাজ করছে কিনা তা চেক করতে পারেন।

## 2. Cancel Subscription (Auto-renew Pause) (`POST /api/v1/subscriptions/auto-renew-pause`)

এই এপিআইটির মাধ্যমে ইউজার তার রানিং সাবস্ক্রিপশন ক্যানসেল বা অটো-রিনিউ পজ করতে পারবে। সাবস্ক্রিপশন ক্যানসেল করলে ইউজারের টাকা রিফান্ড হবে না, তবে সে তার বর্তমান মাসের/বছরের মেয়াদ শেষ হওয়া পর্যন্ত সার্ভিসটি ব্যবহার করতে পারবে।

### Request Details
- **Method:** `POST`
- **URL:** `{{base_url}}/api/v1/subscriptions/auto-renew-pause`
- **Headers:**
  - `Authorization`: `Bearer {{access_token}}`

### Responses

#### 🟢 Success Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Subscription canceled successfully. You will not be charged again. You will continue to have access until the end of your current billing cycle. Please note that no refunds are provided for partial months.",
  "data": { ... }
}
```

### Request Details
- **Method:** `POST`
- **URL:** `{{base_url}}/api/v1/subscriptions/resume`
- **Headers:**
  - `Authorization`: `Bearer {{access_token}}`

### Responses

#### 🟢 Success Response (200 OK)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Subscription auto-renewal has been successfully resumed.",
  "data": { ... }
}
```
