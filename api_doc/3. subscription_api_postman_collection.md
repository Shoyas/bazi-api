# Postman Testing: Subscription API Endpoints

এখানে `Subscription` মডিউলের API গুলো Postman-এ টেস্ট করার জন্য রিকোয়েস্ট এবং রেসপন্সের উদাহরণ দেওয়া হলো। 

> [!IMPORTANT]
> **Authorization Required:** 
> এই রাউটটি `authGuard()` দিয়ে প্রোটেক্টেড, তাই শুধুমাত্র লগিন করা ইউজাররাই এক্সেস পাবে। Postman-এ রিকোয়েস্ট পাঠানোর সময় `Authorization` হেডারে `Bearer <user_access_token>` দিতে ভুলবেন না।

---

## 1. Get Checkout URL (`POST /api/v1/subscriptions/checkout`)

এই এপিআইটির মাধ্যমে ইউজাররা লেমনস্কুইজি (LemonSqueezy) সাবস্ক্রিপশন চেকআউটের লিংক জেনারেট করতে পারবে।

**Request Body (JSON):**
```json
{
  "plan": "MONTHLY"
}
```
*(Available Options: `"MONTHLY"` বা `"YEARLY"`)*

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Checkout URL generated successfully",
  "data": {
    "checkoutUrl": "https://your-store.lemonsqueezy.com/checkout/buy/variant_id?custom=some_custom_data"
  }
}
```

*(নোট: `data` অবজেক্টের স্ট্রাকচার আপনার `SubscriptionService` থেকে যেভাবে রিটার্ন করা হয়েছে ঠিক সেরকম আসবে, সাধারণত একটি পেমেন্ট URL রিটার্ন হয়ে থাকে।)*
