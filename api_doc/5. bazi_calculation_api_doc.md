# BaZi Calculation API Documentation

Welcome to the **BaZi API Calculation Engine** documentation. This endpoint computes the complete Four Pillars of Destiny (八字) chart, including Heavenly Stems, Earthly Branches, Hidden Stems, Five Element statistics, Ten Gods, Na Yin, Shen Sha (Gods & Stars), Twelve Growth Stages, Luck Pillars, and Annual Fortunes.

---

## Endpoint Overview

| Property | Value |
| :--- | :--- |
| **Method** | `POST` |
| **URL Path** | `/api/v1/bazi/calculate` |
| **Authentication** | `x-api-key` Header |
| **Content-Type** | `application/json` |
| **Average Latency** | `< 250ms` (Edge-cached) |

---

## Authentication

Every request to the calculation endpoint must provide a valid API Key in the request header:

```http
x-api-key: bazi_your_api_key_here
```

> **Note:** Generate and manage your API keys from your user dashboard. Free tier accounts support 1 active key, while paid tiers support up to unlimited active keys.

---

## Request Parameters

### Request Body (JSON)

| Field | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `birthDate` | `string` | **Yes** | — | Birth date in `YYYY-MM-DD` format (e.g. `"1998-08-12"`). |
| `birthTime` | `string` | **Yes** | — | Birth time in 24-hour `HH:mm` format (e.g. `"10:30"` or `"14:15"`). If exact time is unknown, use `"12:00"`. |
| `gender` | `string` | **Yes** | — | Biological gender for Luck Pillar calculation: `"male"` or `"female"`. |
| `timezone` | `string` | No | `"Asia/Shanghai"` | Valid IANA Timezone identifier (e.g., `"Asia/Dhaka"`, `"America/New_York"`, `"Europe/London"`). |
| `language` | `string` | No | `"en"` | Response language representation: `"en"` (English translations & labels) or `"zh"` (Traditional/Simplified Chinese characters). |

### Example Request Body

```json
{
  "birthDate": "1998-08-12",
  "birthTime": "10:30",
  "gender": "male",
  "timezone": "Asia/Shanghai",
  "language": "en"
}
```

## Code Examples

### 1. cURL

```bash
curl -X POST https://api.bazi-api.com/api/v1/bazi/calculate \
  -H "x-api-key: bazi_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "birthDate": "1998-08-12",
    "birthTime": "10:30",
    "gender": "male",
    "timezone": "Asia/Shanghai",
    "language": "en"
  }'
```

### 2. Node.js / TypeScript (Axios)

```typescript
import axios from 'axios';

async function calculateBazi() {
  try {
    const response = await axios.post(
      'https://api.bazi-api.com/api/v1/bazi/calculate',
      {
        birthDate: '1998-08-12',
        birthTime: '10:30',
        gender: 'male',
        timezone: 'Asia/Shanghai',
        language: 'en',
      },
      {
        headers: {
          'x-api-key': process.env.BAZI_API_KEY,
          'Content-Type': 'application/json',
        },
      }
    );

    console.log('BaZi Chart Data:', response.data.data);
  } catch (error: any) {
    console.error('API Error:', error.response?.data || error.message);
  }
}

calculateBazi();
```

### 3. Python (Requests)

```python
import requests
import os

url = "https://api.bazi-api.com/api/v1/bazi/calculate"
headers = {
    "x-api-key": os.getenv("BAZI_API_KEY", "bazi_your_key_here"),
    "Content-Type": "application/json"
}
payload = {
    "birthDate": "1998-08-12",
    "birthTime": "10:30",
    "gender": "male",
    "timezone": "Asia/Shanghai",
    "language": "en"
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

if response.status_code == 200:
    print("Day Master:", data["data"]["heavenlyStems"]["dayStem"])
    print("Luck Pillars:", data["data"]["luckPillars"]["pillars"])
else:
    print("Error:", data)
```

## Error Codes & Troubleshooting

| HTTP Status | Message | Solution |
| :--- | :--- | :--- |
| `400 Bad Request` | `Invalid birth date or time format` | Verify date matches `YYYY-MM-DD` and time matches `HH:mm`. |
| `401 Unauthorized` | `API Key is missing or invalid` | Ensure `x-api-key` header starts with `bazi_` and matches your dashboard key. |
| `403 Forbidden` | `User account is disabled or blocked` | Ensure your account is active and verified. |
| `429 Too Many Requests` | `Rate limit exceeded` | You have exceeded your tier quota. Wait for window reset or upgrade your subscription plan. |
