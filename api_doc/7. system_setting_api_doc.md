# System Settings API Documentation

Welcome to the **System Settings Management API** documentation. This module allows **ADMIN** and **SUPER_ADMIN** users to view and update dynamic system-wide configuration keys (such as rate-limit penalty duration, free account retention threshold, and free API key expiration period) in real-time without restarting the backend.

---

## Overview

| Property | Value |
| :--- | :--- |
| **Base URL Path** | `/api/v1/system-settings` |
| **Authentication** | Bearer JWT Token (`Authorization: Bearer <token>`) |
| **Required Roles** | `ADMIN`, `SUPER_ADMIN` |
| **Content-Type** | `application/json` |

---

## Dynamic Settings Keys Supported

| Key | Default Value | Description |
| :--- | :---: | :--- |
| `rate_limit_block_minutes` | `"15"` | Duration (in minutes) an IP / User is temporarily blocked after exceeding rate limits. |
| `free_user_retention_days` | `"180"` | Threshold (in days) after which inactive FREE accounts are automatically disabled/blocked. |
| `free_api_key_expiry_days` | `"30"` | Threshold (in days) after which FREE tier API keys expire and must be rotated. |

## Endpoints Reference

### 1. Get All System Settings (`GET /api/v1/system-settings`)

Retrieve a list of all dynamic system configuration keys and their current values.

**Headers:**
```http
Authorization: Bearer <admin_jwt_token>
```

**Success Response (`200 OK`):**

### 2. Update System Setting (`PATCH /api/v1/system-settings/:key`)

Update the value and optional description for a specific configuration key.

**Headers:**
```http
Authorization: Bearer <admin_jwt_token>
Content-Type: application/json
```

**URL Parameters:**
* `key` (required) — The setting key to update (e.g. `rate_limit_block_minutes`, `free_user_retention_days`, `free_api_key_expiry_days`).

**Request Body (JSON):**
```json
{
  "value": "30",
  "description": "Updated rate limit block penalty to 30 minutes"
}
```

**Success Response (`200 OK`):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "System setting updated successfully",
  "data": {
    "id": "e9b21f3a-1234-4a5b-9c7d-8e9f01234567",
    "key": "rate_limit_block_minutes",
    "value": "30",
    "description": "Updated rate limit block penalty to 30 minutes",
    "updatedAt": "2026-08-16T16:00:00.000Z"
  }
}
```

## Error Handling

| HTTP Status | Reason | Solution |
| :--- | :--- | :--- |
| `401 Unauthorized` | Missing or invalid admin JWT token. | Provide a valid Bearer token for an admin account. |
| `403 Forbidden` | User role is `USER`. | Only `ADMIN` and `SUPER_ADMIN` roles can view or modify system settings. |
| `404 Not Found` | Key does not exist in settings. | Check the key name and ensure it matches the supported list. |
