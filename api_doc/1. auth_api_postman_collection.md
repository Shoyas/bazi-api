# Postman Testing: Auth API Endpoints

Here are the example `request body` and expected `response body` formats for testing all `auth` APIs in Postman. Make sure to set the `Content-Type` header to `application/json` for POST requests.

---

## 1. Register User (`POST /api/v1/auth/register`)

**Request Body (JSON):**
```json
{
  "name": "John Doe",
  "email": "john.doe@example.com",
  "password": "password123",
  "country": "Bangladesh"
}
```
*(Note: `country` is optional)*

**Success Response (201 Created):**
```json
{
  "success": true,
  "statusCode": 201,
  "message": "User registered successfully. Please check your email for verification.",
  "data": {
    "id": "uuid-string-here",
    "name": "John Doe",
    "email": "john.doe@example.com",
    "country": "Bangladesh",
    "isEmailVerified": false,
    "role": "USER",
    "createdAt": "2026-08-09T10:00:00.000Z",
    "updatedAt": "2026-08-09T10:00:00.000Z"
  }
}
```

---

## 2. Verify Email (`POST /api/v1/auth/verify-email`)

**Request Body (JSON):**
```json
{
  "email": "john.doe@example.com",
  "otp": "123456"
}
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Email verified successfully",
  "data": null
}
```

---

## 3. Login User (`POST /api/v1/auth/login`)

**Request Body (JSON):**
```json
{
  "email": "john.doe@example.com",
  "password": "password123"
}
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "User logged in successfully",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5c...",
    "user": {
      "id": "uuid-string-here",
      "name": "John Doe",
      "email": "john.doe@example.com",
      "role": "USER"
    }
  }
}
```
*(Note: `refreshToken` is also set automatically in your HttpOnly Cookies)*

---

## 4. Refresh Token (`POST /api/v1/auth/refresh-token`)

**Request Body (JSON):**
*(Normally, you don't need a body if Postman sends the `refreshToken` Cookie. If testing without cookies, you can pass it in the body)*
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5c..."
}
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Token refreshed successfully",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5c..."
  }
}
```

## 7. Change Password (`POST /api/v1/auth/change-password`)

> [!IMPORTANT]
> **Authorization Required:** Add a header `Authorization: Bearer <your_access_token>` in Postman.

**Request Body (JSON):**
```json
{
  "oldPassword": "newpassword123",
  "newPassword": "brandnewpassword123"
}
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Password changed successfully",
  "data": null
}
```

---

## 9. Logout (`POST /api/v1/auth/logout`)

> [!IMPORTANT]
> **Authorization Required:** Add a header `Authorization: Bearer <your_access_token>` in Postman.

**Request Body:**
*(None required, but must include cookie or token in body for full logout)*

```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5c..."
}
```
*(If the refresh token is in a secure cookie, you may not need to send a body, depending on the controller's implementation)*

**Success Response (200 OK):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Logged out successfully",
  "data": null
}
```
